When work changes hands, chat history is a poor place to keep decisions. PowerContext stores the evidence, decisions, and handoff state so the next person or agent can continue. It runs as its own context service. It is not a chat transcript store.

<img src="/assets/readme-workflow.svg" alt="You begin a task, an agent moves it forward, and you or another agent continues later. Context stays with the work." />

PowerContext 101 covers working paths and integration boundaries. For install options, complete interfaces, and deployment, use the [official PowerContext docs](https://oceanbase.github.io/powercontext/).

Start with one result you can check: write a Memory, find it, then get a cited PreparedContext. That loop proves the Server and Scope before a framework, host hook, or model provider adds another failure boundary.

## A 30-second mental model

PowerContext runs three paths at once. They may cite one another. They do not collapse into one lifecycle.

Keep knowledge. A <Tooltip headline="Source" tip="Records what happened. Capture does not write durable knowledge." cta="Read Source" href="/en/mental-model/source">Source</Tooltip> only proves that something happened. Write a <Tooltip headline="Memory" tip="Selected project knowledge that should matter later." cta="Read Memory" href="/en/mental-model/memory">Memory</Tooltip> when you will reuse it. The next request recalls it through a <Tooltip headline="PreparedContext" tip="A bounded view for one request. It includes Citations and is not a durable asset." cta="Read the mental model overview" href="/en/mental-model/overview">PreparedContext</Tooltip>.

Review first. <Tooltip headline="Experience" tip="Approved judgment for similar situations. It enters Review as a Candidate." cta="Read Experience and Skill" href="/en/mental-model/experience-and-skill">Experience</Tooltip> and managed <Tooltip headline="Skill" tip="An approved repeatable method. Export is still required. PowerContext grants no execution authority." cta="Read Experience and Skill" href="/en/mental-model/experience-and-skill">Skill</Tooltip> first become a <Tooltip headline="Candidate" tip="An Experience or Skill proposal awaiting Review." cta="Read Experience and Skill" href="/en/mental-model/experience-and-skill">Candidate</Tooltip>. A model may draft it. Successful generation is not approval. <Tooltip headline="Review" tip="Approve creates an Artifact Revision. Reject records the reason and creates no result Artifact." cta="Read Experience and Skill" href="/en/mental-model/experience-and-skill">Review</Tooltip> decides what stays. An approved Skill still needs an explicit export.

A handoff can stay temporary. A <Tooltip headline="Handoff" tip="Packages the current objective, verified progress, blockers, and next action. It stays temporary until an explicit commit." cta="Read Handoff" href="/en/mental-model/handoff">Handoff</Tooltip> is packed for the next actor. It becomes a durable milestone only after an explicit commit.

<img src="/assets/start-object-flow-en.svg" alt="Understand PowerContext in 30 seconds: keep knowledge, review first, and hand off work as three separate paths." />

<Tooltip headline="PreparedContext" tip="A bounded view for one request. It includes Citations and is not a durable asset." cta="Read the mental model overview" href="/en/mental-model/overview">PreparedContext</Tooltip> lasts for one request. It includes Citations and is labeled as untrusted historical evidence. An agent may use it as evidence. The text cannot grant tools or replace current system and user instructions.
