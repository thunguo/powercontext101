# PowerContext 101

Bilingual (中文 / English) tutorial site for PowerContext usage and development practice.

This site is a learning path, not a replacement for the [official PowerContext docs](https://oceanbase.github.io/powercontext/).

## Local preview

```bash
npm i -g mint
```

```bash
mint dev
```

Open `http://localhost:3000`. Chinese is the default locale.

## Content rules

See [AGENTS.md](AGENTS.md). Every content change must update `zh/` and `en/` together.
