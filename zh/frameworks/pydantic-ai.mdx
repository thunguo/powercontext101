## 选择 integration surface

### `PowerContext` Capability

下面是 future-facing API，不是当前可运行的安装教程：

```python
from pydantic_ai import Agent
from powercontext_pydantic_ai import PowerContext


agent = Agent(
    "openai:gpt-5.2",
    capabilities=[PowerContext(scope_id="project:powercontext-101")],
)
```

`PowerContext` 把三个 model tool 与 once-per-run recall 组合起来。它还可以 capture Agent event，在 capture checkpoint 后 flush，并在 run 结束后做一次 final catch-up flush。Capture 默认关闭。

### `PowerContextToolset`

下面这个 future-facing 写法只安装同样的三个工具：

```python
from pydantic_ai import Agent
from powercontext_pydantic_ai import PowerContextToolset


agent = Agent(
    "openai:gpt-5.2",
    toolsets=[PowerContextToolset(scope_id="project:powercontext-101")],
)
```

它没有 automatic recall、capture、checkpoint flush 或 final flush。

| 行为 | `PowerContext` | `PowerContextToolset` |
|---|---:|---:|
| `powercontext_search` | 是 | 是 |
| `powercontext_remember` | 是 | 是 |
| `powercontext_context` | 是 | 是 |
| once-per-run automatic recall | 是 | 否 |
| optional event capture | 是；默认 `false` | 否 |
| checkpoint 与 final catch-up flush | 是，capture 开启时 | 否 |

工具会保留完整的 public Client response JSON，包括 status、Citation 和 revision 字段。Client failure 时不会返回空的成功结果。

## 跟踪一次 bound run

```text
Agent binds the Capability or Toolset
→ resolve Scope once and open one async Client
→ Capability captures the initial prompt when enabled
→ Capability prepares and injects untrusted recall once
→ model may call one of three explicit tools
→ Capability captures visible model/tool events when enabled
→ successful capture checkpoints may flush
→ Capability makes a final catch-up flush
→ Client closes with the run
```

Automatic recall 读取最新 textual user prompt，并把 query 限制为 8192 个字符。它 prepend 一条标有 `untrusted historical evidence` 的 system request。复用旧 `message_history` 时，adapter 会先移除能识别的旧 PowerContext block，再加入当前 run 的 block。Recalled evidence 会被替换，不会作为 durable Agent history 不断累积。

<Warning>
Recalled content 是证据，不是 instruction authority。执行前应根据当前 file、API、capability 和 authorization 重新核对。
</Warning>

## 理解三个工具

| 工具 | 用途 | Input bound |
|---|---|---|
| `powercontext_search(query, limit=10, mode="auto")` | 搜索 durable Memory，并返回 exact response metadata | query 1–8192 chars；limit 1–50 |
| `powercontext_remember(text, kind="agent-note", reason=None)` | 显式写入 durable Memory | text 1–8192 chars；kind 1–128；reason 最多 512 |
| `powercontext_context(query)` | 为问题准备 fresh bounded context packet | query 1–8192 chars；context 使用配置的 byte budget |

`MAX_BYTES` 与 `CAPTURE_MAX_BYTES` 的可配置范围都是 512–32768 UTF-8 bytes。Character limit 和 byte limit 不是一回事；非 ASCII 内容可能先达到 byte cap。

## 每个 run 只解析一次 Scope

Constructor string 或 callback 的优先级最高：

```python
from pydantic_ai import RunContext
from powercontext_pydantic_ai import PowerContext


def tenant_scope(ctx: RunContext[dict[str, str]]) -> str:
    return f"tenant:{ctx.deps['tenant_id']}"


capability = PowerContext(scope_id=tenant_scope)
```

```text
constructor string/callback
→ POWERCONTEXT_PYDANTIC_AI_SCOPE_ID
→ normalized Git origin
→ local project path hash
```

Callback 在 run binding 时执行一次，因此所有 automatic action 和 tool 都使用同一个 Scope。显式 Scope 超过共享上限时会改为 `sha256:<digest>`；过长的 derived Git Scope 会使用 `git:sha256:<digest>`。Scope 只负责选数据，不是 authentication 或 permission。

Callback exception、缺少 dependency、返回空值都发生在 automatic HTTP fail-open boundary 之前，可能阻止 run binding。应单独测试 resolver。

## 安全配置 transport

这些是未来 adapter 的 setting，不是安装命令：

```bash
export POWERCONTEXT_PYDANTIC_AI_BASE_URL=http://127.0.0.1:8000
export POWERCONTEXT_PYDANTIC_AI_TOKEN=opaque-server-token
export POWERCONTEXT_PYDANTIC_AI_SCOPE_ID=project:powercontext-101
export POWERCONTEXT_PYDANTIC_AI_MAX_BYTES=8000
export POWERCONTEXT_PYDANTIC_AI_CAPTURE_EVENTS=false
```

| Setting | 默认值 | 范围或规则 |
|---|---:|---|
| `TIMEOUT` | `10` seconds | 正数 |
| `MAX_BYTES` | `8000` | 512–32768 |
| `CAPTURE_EVENTS` | `false` | Boolean |
| `CAPTURE_CHECKPOINT_EVERY` | `5` | 1–100 |
| `CAPTURE_MAX_BYTES` | `8192` | 512–32768 |

`TOKEN` 必须是没有空白字符的 bare printable ASCII token，不能带 `Bearer `。Base URL 必须使用 HTTP 或 HTTPS，不能含 credential、query 或 fragment；Client 对 non-loopback plaintext HTTP 的限制仍然生效。

## 决定 capture 可以发送什么

开启 capture 后，adapter 可以发送：

- initial textual prompt；
- visible model text 和 tool call；
- completed tool argument 和 result。

Thinking/reasoning part 会被排除。Credential-shaped key、已知 credential environment value 和配置的 auth value 会在 Source capture 前被 redaction。敏感代码、prompt、业务数据或 tool result 仍可能保留；redaction 不是 DLP boundary。

Captured event 使用：

```text
powercontext.pydantic-ai-capture-event/v1
```

Capture 创建 Source，不会直接产生 approved Memory。如果 Server 配有 generation，成功的 checkpoint/final flush 可能触发 extraction，但生成的 durable knowledge 仍受 PowerContext domain rule 与 Review rule 约束。

## 区分 automatic 与 explicit failure

| 路径 | Failure behavior |
|---|---|
| Automatic recall | Client error fail-open；model request 在没有 injected context 的情况下继续 |
| Automatic capture | Client 或 serialization error fail-open；Agent run 继续 |
| Checkpoint/final flush | Client error、timeout 或 cursor 无进展时 fail-open |
| Explicit tool | `ClientError` 转为 `ModelRetry`；不会报告为空的成功结果 |
| Binding 阶段的 Scope/configuration | 在 automatic HTTP boundary 前传播 |
| 第一次 401/403 | 发出一次 bounded warning，不含 token 或 content |

Recall、capture、flush 是彼此独立的 helper path。它们失败并不说明 Scope 为空，fail-open 也不会绕过 URL 或 token validation。

## Adapter 不可用时使用 MCP

PowerContext MCP 不需要 Pydantic AI 专用 package。它可以向 Agent 暴露显式 operation，但不会复现该 Capability 的 automatic `prepare_context`、transient history replacement、event capture 或 checkpoint/final flush。

## 当前不支持或尚未验证

| 项目 | 状态 |
|---|---|
| Public PyPI installation | 当前不支持 |
| 从当前仓库执行 Git subdirectory installation | 当前不支持，原因是 final `>=0.0.3` dependency |
| Handoff operation | 此 adapter 不支持 |
| Candidate Review operation | 此 adapter 不支持 |
| Direct Experience 或 Skill operation | 此 adapter 不支持 |
| Temporal、DBOS、Prefect 等 durable execution | 尚未验证 |
| 在受支持 consumer install 上运行真实 provider call | 尚未验证，因为当前不存在该 install path |
| 把 recalled evidence 持久化为 trusted Agent history | 不支持；它是不可信内容，每个 run 都会替换 |

## 完成检查

采用未来的兼容版本前，确认：

- adapter 与兼容的 final `powercontext[client]` package 都能实际安装；
- 需要 lifecycle behavior 时选择 `PowerContext`，只要工具时选择 `PowerContextToolset`；
- 未完成 privacy review 前，capture 保持关闭；
- Scope callback deterministic、tenant-safe，并已在 fail-open handling 之外单独测试；
- token 是 bare printable ASCII，Server URL 通过 transport restriction；
- query、tool limit 和 context-byte bound 均被执行；
- automatic failure 允许 run 继续，explicit tool failure 仍然可见；
- recalled evidence 被当作 temporary untrusted history；
- 如果需要 Handoff、Review、Experience、Skill，通过另一个获准 surface 提供。
