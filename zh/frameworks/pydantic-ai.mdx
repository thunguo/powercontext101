## 本页将覆盖

- `PowerContext` Capability：三个工具、每 run 自动 recall，以及可选 capture / flush
- `PowerContextToolset`：只提供三个显式工具
- per-run Scope callback、history replacement 与隐私边界
- 自动路径 fail-open 与显式工具 `ModelRetry` 的区别
- 当前不支持的 Handoff、Review、Experience / Skill 操作
