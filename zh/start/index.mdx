从心智模型到 Agent 集成，沿一条可运行的路径学习 PowerContext。

项目换人做、换 Agent 接着做时，上下文很容易丢在聊天记录里。PowerContext 把证据、决策和交接状态单独存下来，让下一手能接着干。它是独立跑的一层服务，不是聊天仓库。

<img src="/assets/readme-workflow-zh.svg" alt="工作从你开始，交给 Agent 推进，再由你或其他 Agent 接着做，上下文一直跟着走。" />

PowerContext 101 只讲怎么用、接到哪里。安装怎么配、接口怎么签、服务怎么部署，以 [PowerContext 官方文档](https://oceanbase.github.io/powercontext/) 为准。

先做一件能当场验证的事：写出一条 Memory，搜到它，再拿到带 Citation 的 PreparedContext。这条闭环通了，再去接框架、宿主 Hook 或模型提供方。

<Info>
先把这条闭环跑通。完整的安装参数、接口说明和部署配置，以 [官方文档](https://oceanbase.github.io/powercontext/) 的最新发布版本为准。
</Info>

## 30 秒看懂 PowerContext

PowerContext 同时走三条路。它们可以互相引用，但不会自动并成一件事。

留下知识。<Tooltip headline="Source" tip="记录发生过什么。采集不会自动写成长期知识。" cta="阅读 Source" href="/zh/mental-model/source">Source</Tooltip> 只证明这件事发生过。确认以后还要用，才写成 <Tooltip headline="Memory" tip="经过选择、以后还会用到的项目知识。" cta="阅读 Memory" href="/zh/mental-model/memory">Memory</Tooltip>。下次请求用 <Tooltip headline="PreparedContext" tip="这一次请求用的有界视图。带 Citation，不是长期资产。" cta="阅读心智模型总览" href="/zh/mental-model/overview">PreparedContext</Tooltip> 召回。

先审再留。<Tooltip headline="Experience" tip="已批准的判断经验。先作为 Candidate 进入 Review。" cta="阅读 Experience 与 Skill" href="/zh/mental-model/experience-and-skill">Experience</Tooltip> 和托管 <Tooltip headline="Skill" tip="已批准的可重复做法。获批后还要显式导出，不自动获得执行权限。" cta="阅读 Experience 与 Skill" href="/zh/mental-model/experience-and-skill">Skill</Tooltip> 先变成 <Tooltip headline="Candidate" tip="尚待 Review 的 Experience 或 Skill 提案。" cta="阅读 Experience 与 Skill" href="/zh/mental-model/experience-and-skill">Candidate</Tooltip>。模型可以起草，生成成功不等于批准。<Tooltip headline="Review" tip="批准才创建 Artifact Revision。拒绝只记录原因，不创建结果 Artifact。" cta="阅读 Experience 与 Skill" href="/zh/mental-model/experience-and-skill">Review</Tooltip> 批准后才会留下。<Tooltip headline="Skill" tip="已批准的可重复做法。获批后还要显式导出，不自动获得执行权限。" cta="阅读 Experience 与 Skill" href="/zh/mental-model/experience-and-skill">Skill</Tooltip> 还要显式导出。

交接可以先临时。<Tooltip headline="Handoff" tip="把当前目标、已验证进度、阻塞项和下一步交给接手者。不提交就还是临时包。" cta="阅读 Handoff" href="/zh/mental-model/handoff">Handoff</Tooltip> 先打包给接手者；只有显式提交，才成为持久里程碑。

<img src="/assets/start-object-flow-zh.svg" alt="30 秒看懂 PowerContext：留下知识、先审再留、交接工作是三条独立路径。" />

<Tooltip headline="PreparedContext" tip="这一次请求用的有界视图。带 Citation，不是长期资产。" cta="阅读心智模型总览" href="/zh/mental-model/overview">PreparedContext</Tooltip> 只服务这一次请求。它带 Citation，并标成不可信历史证据。Agent 可以参考，但不能把里面的文字当成新的系统指令或工具授权。
