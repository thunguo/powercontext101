先读心智模型，再跑通本地 Server，然后只选一条路径走完最小闭环。查契约时离开 101，打开官方文档。

<Steps titleSize="h3">
  <Step title="读心智模型" icon="brain">
    先立住 Source、Memory、Handoff、Experience / Skill，再读 Scope 和 fail-open。从[心智模型总览](/zh/mental-model/overview)开始。
  </Step>
  <Step title="跑通本地 Server" icon="server">
    官方前提是 macOS 或 Linux、Python 3.11+ 和 `uv`。安装与健康检查写在[安装并运行 Server](/zh/basic-usage/install-and-run)。更细的命令和部署看[官方安装指南](https://oceanbase.github.io/powercontext/zh/docs/how-to/install-and-run/)。
  </Step>
  <Step title="选一条实战路径" icon="route">
    用下面的身份 Tab 选路，并走完该路径的最小闭环。不要同时开四条线。
  </Step>
  <Step title="查契约时离开 101" icon="book-open">
    HTTP、配置默认值、OpenAPI 和逐步 how-to 属于[官方文档](https://oceanbase.github.io/powercontext/zh/docs/)。101 只教怎么用、怎么玩。
  </Step>
</Steps>

<Warning>
官方安装路径是 macOS 或 Linux。本页不写 Windows 变通，避免把它写成未验证教程。
</Warning>

<Tip>
显式 Memory 不必先配 inference provider。只有要从 Source 自动抽取 Memory 时，才需要配置生成模型。
</Tip>

## 按身份选路

<Tabs>
  <Tab title="我写 Python Agent">
    顺序：心智模型 → [安装并运行 Server](/zh/basic-usage/install-and-run) → [常用 API 串讲](/zh/basic-usage/api-tour) → [框架集成](/zh/frameworks/overview)。

    最小闭环是：Python Client 跑通 `remember`、`search` 和 `prepare_context`，再接到 LangGraph 或 LangChain。Pydantic AI 仍是预览，不能当成可独立安装的路径。
  </Tab>
  <Tab title="我用编程 Agent">
    顺序：心智模型 → [安装并运行 Server](/zh/basic-usage/install-and-run) → [编程 Agent](/zh/coding-agents/overview)，再选 Codex、Claude Code、DSH、OpenCode 或 Pi。

    最小闭环是：`powercontext setup <host>`、`powercontext doctor`，然后在新会话里召回一条你自己写下的 Memory。
  </Tab>
  <Tab title="我用 Hermes / OpenClaw">
    顺序：心智模型 → [安装并运行 Server](/zh/basic-usage/install-and-run) → [Hermes](/zh/common-agents/hermes) 或 [OpenClaw](/zh/common-agents/openclaw)。

    最小闭环是：`powercontext setup <host>`、`powercontext doctor`，再把对应宿主页贴给 Agent，让它自己完成配置。Hermes 在 setup 之后还要运行 `hermes memory setup`，并选择 PowerContext。逐步命令见[官方 Hermes 指南](https://oceanbase.github.io/powercontext/zh/docs/how-to/configure-hermes/)。
  </Tab>
</Tabs>

## 最小闭环

做到这些，再往下翻 tricks。

<Columns cols={2}>
  <Card title="基础用法" icon="book-open" href="/zh/basic-usage/install-and-run" arrow="true" cta="开始闭环">
    Client 能 `remember`、`search`、`prepare_context`，并且你分得清 Source 和 Memory。
  </Card>
  <Card title="框架集成" icon="boxes" href="/zh/frameworks/overview" arrow="true" cta="看适配器">
    图或 agent 连上同一个 Server，召回和采集 fail-open。Pydantic AI 只读预览页。
  </Card>
  <Card title="通用 Agent" icon="bot" href="/zh/common-agents/overview" arrow="true" cta="去可贴配置">
    setup、doctor，再把宿主页交给 Agent。Agent 能自己完成配置。
  </Card>
  <Card title="编程 Agent" icon="terminal" href="/zh/coding-agents/overview" arrow="true" cta="看合同">
    setup、doctor，新会话能召回你写下的 Memory。Hook 做 recall / capture，插件做显式写。
  </Card>
</Columns>
