---
title: "Handoff 闭环"
description: "创建 Work Contract，交接当前工作，确认 exact Handoff，并记录真实 Task Outcome。"
---

这一页完成一条真正的工作交接：发送方记录委托边界和当前状态，接收方检查 exact Handoff，最后把结果链接回这次交接。

Handoff 不要求 generation model。示例使用调用方已经检查过的 typed data，最小 Server 就能运行。

## 闭环长什么样

```text
Work Contract
→ handoff_current_work
→ Prepared Handoff
→ optional commit
→ continue exact
→ acknowledge exact
→ Task Outcome
```

Work Contract、Handoff boundary、acknowledgement receipt 和 Task Outcome 都会留下 Source receipt。Committed Handoff 另有不可变 Artifact Revision。

## 完整 Python 示例

新建 `handoff_loop.py`：

```python
import asyncio
import os
from uuid import uuid4

from powercontext.client import PowerContextClient
from powercontext.http import (
    AcknowledgeHandoffRequest,
    CommitHandoffRequest,
    ContinueHandoffRequest,
    CreateWorkContractRequest,
    HandoffCurrentWorkRequest,
    RecordTaskOutcomeRequest,
)


SERVER_URL = os.getenv(
    "POWERCONTEXT_CLIENT_SERVER_URL",
    "http://127.0.0.1:8000",
)
API_TOKEN = os.getenv("POWERCONTEXT_CLIENT_API_TOKEN")


async def main() -> None:
    run_id = uuid4().hex
    scope_id = f"project:powercontext-101:{run_id}"

    async with PowerContextClient(
        SERVER_URL,
        token=API_TOKEN,
        timeout=10.0,
    ) as client:
        contract = await client.create_work_contract(
            CreateWorkContractRequest.model_validate({
                "scope_id": scope_id,
                "source_id": f"contract-{run_id}",
                "contract": {
                    "schema": "powercontext.work-contract.v1",
                    "trust": "untrusted_input",
                    "objective": "Complete the OpenAPI client update.",
                    "facts": [{
                        "text": "The repository has contract tests.",
                        "basis": "declared",
                        "evidence": [],
                    }],
                    "in_scope": ["Regenerate the checked-in client."],
                    "exclusions": ["Do not deploy to production."],
                    "completion_criteria": ["Contract tests pass."],
                    "authorization_notes": [
                        "This contract does not grant deployment authority."
                    ],
                    "open_questions": [],
                },
            })
        )
        print("contract receipt:", contract.source, contract.position)

        prepared_work = await client.handoff_current_work(
            HandoffCurrentWorkRequest.model_validate({
                "scope_id": scope_id,
                "source_id": f"boundary-{run_id}",
                "handoff": {
                    "schema": "powercontext.current-work-handoff.v1",
                    "trust": "untrusted_input",
                    "objective": "Complete the OpenAPI client update.",
                    "state": [{
                        "text": "The checked-in client was regenerated.",
                        "basis": "declared",
                        "evidence": [],
                    }],
                    "disposition": "continuable",
                    "next_action": {
                        "text": "Run contract tests.",
                        "basis": "declared",
                        "evidence": [],
                    },
                    "omissions": ["Contract tests have not run yet."],
                },
            })
        )
        print("boundary receipt:", prepared_work.boundary.source)
        print("prepared base:", prepared_work.handoff.base)

        temporary = await client.continue_handoff(
            ContinueHandoffRequest(
                scope_id=scope_id,
                selection="prepared",
                prepared=prepared_work.handoff,
            )
        )
        assert temporary.status == "resolved"
        assert temporary.selection == "prepared"
        assert temporary.selected_revision is None

        committed = await client.commit_handoff(
            CommitHandoffRequest(
                scope_id=scope_id,
                handoff=prepared_work.handoff,
            )
        )
        print("committed revision:", committed.reference)

        latest = await client.continue_handoff(
            ContinueHandoffRequest(
                scope_id=scope_id,
                selection="latest",
            )
        )
        assert latest.selected_revision == committed.reference
        assert latest.current_revision == committed.reference

        exact = await client.continue_handoff(
            ContinueHandoffRequest(
                scope_id=scope_id,
                selection="exact",
                revision=latest.selected_revision,
            )
        )
        assert exact.selection == "exact"
        assert all(
            check.status == "available"
            for check in exact.evidence_checks
        )

        acknowledgement = await client.acknowledge_handoff(
            AcknowledgeHandoffRequest.model_validate({
                "scope_id": scope_id,
                "source_id": f"receipt-{run_id}",
                "receiver": "contract-test-agent",
                "status": "accepted",
                "selection": "exact",
                "receiver_checks": {
                    "live_state": "confirmed",
                    "capability": "confirmed",
                    "authorization": "confirmed",
                },
                "revision": committed.reference.model_dump(),
            })
        )
        assert acknowledgement.receipt.kind == "handoff-receipt"
        print("ack receipt:", acknowledgement.receipt.source)

        outcome = await client.record_task_outcome(
            RecordTaskOutcomeRequest.model_validate({
                "scope_id": scope_id,
                "source_id": f"outcome-{run_id}",
                "outcome": {
                    "schema": "powercontext.task-outcome.v1",
                    "trust": "untrusted_observation",
                    "objective": "Complete the OpenAPI client update.",
                    "status": "succeeded",
                    "summary": "Contract tests passed.",
                    "handoff_receipt_ref": (
                        acknowledgement.receipt.source.model_dump()
                    ),
                    "observations": [{
                        "text": "The contract tests completed successfully.",
                        "basis": "declared",
                        "evidence": [],
                    }],
                    "checks": [{
                        "name": "Contract tests",
                        "status": "passed",
                        "details": "The command exited successfully.",
                        "basis": "declared",
                        "evidence": [],
                    }],
                    "produced_artifacts": [],
                    "remaining_work": [],
                },
            })
        )
        assert outcome.kind == "task-outcome"
        print("outcome receipt:", outcome.source)


if __name__ == "__main__":
    asyncio.run(main())
```

运行：

```bash
uv run python handoff_loop.py
```

这里用 `model_validate` 构造嵌套 request，因为 JSON 契约中的字段名是 `schema`，而生成的 Python model 内部属性使用别名。

## 每一步的边界

### Work Contract 是委托基线

它记录 objective、in-scope work、exclusions、completion criteria、authorization notes 和 consequential questions。

Contract 是 `untrusted_input` Source，不会扩大当前授权。`basis="verified"` 的 claim 必须带 exact evidence；`basis="declared"` 则不能带 evidence。

### `handoff_current_work` 会写 boundary Source

它返回：

```text
PreparedWorkHandoff
├── boundary: WorkSourceReceipt
└── handoff: PreparedHandoff
```

后续 commit/continue 传 `prepared_work.handoff`，不是整个 response。

这一步没有创建 Handoff Revision，但已经持久化 boundary Source。因此，它不是 read-only preview。

### Prepared transfer 不需要 commit

示例先 `continue_handoff(selection="prepared")`，证明临时交接可用。此时 `selected_revision` 是 `None`。

只有需要 durable milestone 时才调用 `commit_handoff`。

### `latest` 用于发现，`exact` 用于确认

`latest` 返回当前 head，并把它放在 `selected_revision` 和 `current_revision`。接收方检查后，应把 acknowledgement 绑定到 exact Revision。

`acknowledge_handoff` 不接受 `selection="latest"`。

### Accepted 有硬性条件

只有下面三项全部 confirmed，且 evidence 都 available，才能写 `accepted`：

```text
live_state
capability
authorization
```

无法确认时使用 `needs_clarification` 或 `declined`，并提供 message。

Acknowledgement 只是接收记录，不授予权限。

### Outcome 要链接 accepted exact receipt

`handoff_receipt_ref` 使用：

```python
acknowledgement.receipt.source
```

只有 status accepted、selection exact、selected Revision 指向 committed Handoff 的 receipt，才能声明该 durable Handoff 的结果被覆盖。

Prepared acknowledgement receipt 不能用于这个 linkage。

## Outcome 与 Check 状态

整体 `TaskOutcome.status` 可选：

```text
succeeded
partial
blocked
failed
cancelled
unknown
```

单项 `TaskCheck.status` 可选：

```text
passed
failed
skipped
timed_out
unavailable
cancelled
unknown
```

不要因为一个 check passed 就把整体结果写成 succeeded。没运行的检查也不能写 passed。

## 负向实验

### 不 commit，读取 latest

在 commit 前调用 `continue_handoff(selection="latest")`，应得到 `status="empty"`。Prepared Handoff 仍可通过 `selection="prepared"` 使用。

### Accepted 但 authorization 未确认

把 authorization 改成 `not_checked`，operation 应拒绝。改用 `needs_clarification` 并说明缺少什么。

### 用 prepared receipt 记录 committed outcome

先 acknowledgement prepared，再把它作为 `handoff_receipt_ref`。Server 应拒绝，因为 receipt 没有绑定 committed exact Revision。

### 两个 Prepared Handoff 共享 base

先准备两个 Handoff，commit 第一个，再 commit 第二个。第二个应发生 Revision conflict。读取新 head 后重新准备，不要猜 revision。

### Boundary 成功，commit 失败

此时 boundary Source 已存在，但没有新的 Handoff Revision。向用户报告这个实际状态，不能说“什么都没写”，也不能说“里程碑已保存”。

## 完成检查

- Work Contract receipt 已保存；
- Prepared Handoff 可以临时 continue；
- commit 返回 exact Handoff Revision；
- latest discovery 转成 exact acknowledgement；
- accepted 前检查 evidence、live state、capability、authorization；
- Task Outcome 链接 acknowledgement receipt SourceRef；
- overall outcome 与 individual check status 没有混用。
