<Note>
Package runtime 要求 Node `>=22.19`。Pi 0.82.x 是 development compatibility，不是正式最低 host version。Package-load E2E 有覆盖，完整 recall host chain 为 **Not validated**。
</Note>

## 安装

```bash
powercontext setup pi --source oceanbase/powercontext --ref master
powercontext server run
powercontext doctor pi
```

Setup 安装 native package，包含 extension 与 bundled Skill。Doctor 用 `pi list` 检查实际 package path/manifest。

## Turn 与 boundary flush

```text
before_agent_start
→ resolve Scope
→ prepare
→ capture prompt Source
→ immediate flush or record pending position
→ augment systemPrompt

agent_end / session_before_compact / session_before_switch / session_shutdown
→ retry pending flush within bounded budget
```

Flusher 按 Scope 保留最大 pending position，只有 `current_cursor >= position` 才清除。Boundary failure fail-open。

Prompt Source ID 由 branch/turn identity 派生。Secret-looking 或超过 UTF-8 byte limit 的 prompt 不 capture。

## Tools 与确认

Pi 提供 Memory/Handoff tools 和 `/pc` diagnostics。Durable mutation 需要 interactive confirmation；没有 UI 时返回稳定 `confirmation_required`，不会静默写入。

`agent_end` 只触发 flush，不自动记录 Task Outcome。`session_shutdown` 也不是 Claude Code Stop Hook。

Pi 不支持 managed Skill export；bundled Skill 不改变这个事实。

## 负向检查

- Server down：recall/capture/flush 不阻止 Agent。
- Secret/oversized prompt：可 recall，但不 capture。
- Immediate flush 失败：boundary event 重试。
- Cursor 永远追不上：bounded budget 后停止，不谎报 Memory 已生成。
- 无 UI mutation：明确拒绝。
- Redirect/remote transport：按 Pi transport tests 验证，不跨宿主类推。
