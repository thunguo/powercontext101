接第六个宿主前，先确认宿主能提供什么。没有稳定 prompt event、pre-dispatch injection point 或 permission API，就不能照抄现有 adapter。

## Capability discovery

记录：prompt event、turn/session identity、workspace、transient injection channel、tool registration、permission/UI、package/Skill install、headless lifecycle 和 version probe。

## Adapter contract

```text
PromptEvent
ScopeResolver
PreparedContextProvider
TransientInjector
SourceCapture
FlushCoordinator
ToolSurface
PermissionGate
Diagnostics
Installer / Doctor
```

每项写明 input/output、失败策略和可观察 assertion。Automatic helper 可 fail-open；explicit mutation 不可。

## 复用现有实现

- `powercontext.transport` 与 loopback vectors；
- Codex/Claude prepared-context schema validation；
- 各宿主 Scope normalization tests；
- Pi pending flusher；
- DSH OpenAPI-derived operation table；
- Codex/Claude Skill projections；
- `cli/hosts.py` setup/doctor catalog。

当前没有统一 HostAdapter SDK。不要为了文档整齐虚构一个。

## Acceptance tiers

1. Unit contract：schema、Scope、size、secret、permission。
2. Service-chain：真实 Server、Source/Memory lineage、fail-open。
3. Setup/doctor：幂等、ownership、rollback、activation。
4. Real-host E2E：启动宿主，发送 prompt，观察 injection/capture/permission。
5. Negative/security：Server down、wrong auth、redirect、unknown schema、oversize、stale turn、no UI、flush timeout。

Managed Skill export 只有 Codex/Claude Code。新宿主要增加 export，必须单独实现 projection contract 与 drift tests，不能因为有 bundled Skill 就标 Supported。

## 第六个宿主怎么立项

不要先抄 `POST /v1/context/prepare`。按这个顺序写：

1. 先发现宿主 capability：prompt event、injection channel、permission / UI、version probe。缺其中一项，先标 **Unsupported** 或 **Not validated**，不要开 installer。
2. 对照至少两个现有宿主。先读 [Hook 与插件](/zh/coding-agents/hooks-and-plugins)，再比 [OpenCode](/zh/coding-agents/opencode)（真实 host-process E2E 是 **Supported**，且 **Version-gated** `>=1.18.21,<2`）和 [Codex](/zh/coding-agents/codex)（Hook + MCP，真实 host E2E 是 **Not validated**）。
3. 先写测试，再写 adapter。现有分层可以点名这些模块：
   - unit contract：`tests/test_transport.py`、`tests/codex_plugin/test_recall.py`、`tests/claude_code_plugin/test_hook.py`
   - service-chain：`tests/e2e/test_codex_service_chain.py`、`tests/e2e/test_dsh_http_chain.py`
   - setup / doctor：`tests/test_setup_select.py`、`tests/test_doctor_integrations.py`、对应 `tests/test_*_cli.py`
   - real-host E2E：以 `tests/e2e/test_opencode_plugin_host.py` 为标杆；只打 HTTP 的 chain 不算
   - 负向安全：Server down、wrong auth、redirect、unknown schema、oversize、stale turn、no UI
4. 只有 version gate、幂等 setup、activation probe 和 real-host E2E 都齐了，才能把名字加进 `cli/hosts.py` 的 `FIRST_CLASS_HOSTS`。独立 `setup` 命令（例如 WorkBuddy）不自动进入这个 catalog。

当前没有统一 HostAdapter SDK。不要为了对齐文档虚构一个。

## 交付 checklist

- Host version gate 和 activation probe 已实现。
- Scope 来自稳定、授权后的 identity。
- PreparedContext 临时注入且标 untrusted。
- Capture 明确内容、size、secret policy。
- Explicit writes 有 permission/no-UI 行为。
- Diagnostics 不泄密。
- Setup 不覆盖 foreign config，并有 rollback/partial-failure 报告。
- Real-host E2E 存在；仅 HTTP-chain 不算。
- Unsupported 与 Not validated 分开。

完成这些，才把宿主加入 first-class catalog。
